# AI Prompt: Build a Premium 3D Backend Developer Portfolio Website

Create a **world-class, premium, futuristic 3D portfolio website** for a **Backend Software Developer**. The website should feel like a blend of **Apple, Linear, Stripe, Vercel, and Framer**, with subtle 3D interactions and a polished developer aesthetic. Use **mock data only** (do not use any real personal information).

# Final Goal

The final result should feel like a **premium interactive experience**, not just a portfolio. It should immediately communicate the expertise of a backend engineer through **3D visual storytelling**, with interactive system architecture, animated infrastructure, elegant UI, and realistic mock data—showcasing backend concepts such as APIs, databases, caching, messaging, microservices, observability, and cloud infrastructure in a visually compelling yet professional way. The design should be memorable to recruiters while remaining performant, accessible, and production-ready.
